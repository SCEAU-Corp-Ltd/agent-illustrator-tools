# Agent Illustrator Tools

Talk to an AI assistant. It changes your Illustrator artwork.

![How it works](docs/images/how-it-works.svg)

---

## Connect in 3 steps

**1. Open Illustrator (Beta) → Preferences → MCP & Tools**

![MCP & Tools panel](docs/images/mcp-tools-panel.svg)

Tick **Enable MCP server.**

**2. Pick your AI tool and click Connect**

- **Cursor** — click Connect, then Install in Cursor
- **Claude** — copy the command shown, paste into Terminal
- **Codex** — copy the export line shown

**3. Test it**

Open a document in Illustrator, then ask your AI:
> *"List the open Illustrator documents and show me the active artboard."*

If it responds with your file — you're connected.

---

🔒 Never share your token. It changes every time Illustrator restarts.
